## Bug Reports & Feature Requests

- **Bug Reports**: Open an issue using GitHub Issues with synthetic data only. Never paste real personal data.
- **Detection Gaps**: If the Scrubber missed an entity or had a false positive, report it with synthetic examples so we can add it to our test suites.
- **Security Vulnerabilities**: Do **not** open a public issue. Follow our [Security Policy](SECURITY.md) and report privately through GitHub Security → Report a vulnerability.

## Community & Questions

- **GitHub Discussions**: For questions about setup, architecture, or integrations.
- **Contact**: [Open a public GitHub issue](https://github.com/hassanismailtech/Aegis/issues/new) for general questions or feedback. Do not include sensitive personal data.
